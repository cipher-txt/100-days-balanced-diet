# 100 Days — Balanced Diet

A clean, dependency-free 100-day calorie tracking challenge.

## Features

- Choose a start date and daily calorie target.
- Manually add meals and calories.
- Daily target + up to 100 kcal is an allowed overage.
- More than 100 kcal over target fails the day and breaks the streak.
- 100-day visual calendar.
- Current consumption, target, remaining calories and streak.
- Change the target/start date later.
- Export/import your data as JSON.
- Responsive and mobile-friendly.
- No account, server, database or external JavaScript dependencies.
- Data is stored locally in the browser.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages

This repository includes a GitHub Actions workflow that publishes the site to GitHub Pages after pushes to `main`.

## Important

This is a tracking tool, not a medical or nutritional prescription. Users choose their own calorie target. The app should not be used to encourage unsafe restriction or disordered eating.
